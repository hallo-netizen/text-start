# K0 – Zentrale Campus-Textmaschine

K0 ist ein eigenständiger, zentraler Mehrportal-Prototyp.

## Ziel
Eine einzige Textmaschine nimmt einen portalgebundenen Intake entgegen, lädt ausschließlich das passende Portalprofil und erzeugt daraus einen normalisierten Produktionsauftrag.

## Isolation
K0 besitzt keine Laufzeit-, Datei-, Branch-, Artefakt-, Current-, Workflow- oder Importabhängigkeit zu bestehenden Textmaschinen.
K0 liest keine Dateien aus anderen Repositories.
K0 schreibt keine Dateien in andere Repositories.
K0 hat eine eigene Current-Autorität, eigene Verträge, eigene Engine und eigene Tests.

## Noch nicht Bestandteil von K0
- keine Live-Produktion;
- kein WordPress-Schreiben;
- kein Publish;
- keine Übernahme fremder Regelwerke;
- keine Migration bestehender Maschinen.

## Nächste Ausbaustufe
Nach grünem Isolation-/Routing-Test werden die zentralen Produktionsstufen innerhalb von K0 selbst ergänzt: Research, Schreiben, Textregeln, Sprachprüfung, Faktenbindung, Portalbindung und Finalisierung.
