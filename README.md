# text-start

Zentrale Startstelle für Textprojekte.

## Zweck
Dieses Repository darf nur den Start eines freigegebenen Projekts auslösen.

Es enthält keine Artikelregeln, keine Qualitätsregeln und keine Produktionslogik.

## Feste Grundregel
- Der Projekt-Start ist fest verdrahtet.
- Keine freie Auswahl von Datei, Branch, Befehl oder Ziel.
- Artikelinhalt und Qualitätsregeln bleiben im jeweiligen Projekt unverändert.
- Publish bleibt getrennt und ist nicht Bestandteil des Starts.

## Aktueller Pferdeatelier-K0-Einstieg
- Ein berechtigtes GitHub-Konto erstellt ein Issue mit dem exakten Titel `START:pferdeatelier`.
- `text-start` prüft ausschließlich den festen K0-Einstieg `konzept0-portal-neutral-20261002:K0_START_HERE.md` und meldet `K0_ENTRY_VERIFIED`.
- K0 bleibt **unverändert** und wird weiterhin nur von seinem vorhandenen Datei-Auslöser gestartet, sobald der Chat den vollständigen Recherchekontext eingereicht hat. `text-start` erstellt selbst weder Artikel noch den Recherchekontext.
- `K0_ENTRY_VERIFIED` bedeutet geprüfter Einstieg, **nicht** abgeschlossener K0-Produktionsstart.
