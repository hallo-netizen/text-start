# text-start

Zentrale Startstelle für Textprojekte.

## Zweck
Dieses Repository darf nur den Start eines freigegebenen Projekts auslösen.

Es enthält keine Artikelregeln, keine Qualitätsregeln und keine Produktionslogik.

## Feste Grundregel
- Der Projekt-Start ist fest verdrahtet.
- Es ist **kein Batch** und keine Artikelanzahl in `text-start` gebunden.
- Der Ziel-Empfänger ermittelt beim Start automatisch den aktuell freigegebenen 1..N-Auftrag.
- Erst der konkrete Lauf friert diesen Auftrag technisch ein.
- Keine freie Auswahl von Datei, Branch, Befehl oder Ziel.
- Artikelinhalt und Qualitätsregeln bleiben im jeweiligen Projekt unverändert.
- Publish bleibt getrennt und ist nicht Bestandteil des Starts.
